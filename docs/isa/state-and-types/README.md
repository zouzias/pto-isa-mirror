# State, Types, And Location

This chapter describes PTO's type system and location intent model: data types, tile roles, location intent, and legality constraints on operations.

## In This Chapter

- [Type System](type-system.md) — supported element types, vector widths, exceptional floating-point behavior, and conversion rules
- [Layout Reference](layout.md) — layout categories and their role in operand interpretation
- [Data Format Reference](data-format.md) — data format classes used by PTO operations
- [Location Intent And Legality](location-intent-and-legality.md) — location intent categories and the legality checks applied to operations

## Suggested Reading Order

1. Start with [Type System](type-system.md) to understand supported element types and widths.
2. Continue with [Layout Reference](layout.md) and [Data Format Reference](data-format.md) for operand interpretation details.
3. Finish with [Location Intent And Legality](location-intent-and-legality.md) to understand type, layout, and profile constraints.

This chapter corresponds to Chapter 5 of the manual. It provides the type and legality background needed before instruction-level reading.
