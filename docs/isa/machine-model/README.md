This chapter describes PTO's execution model: execution agents, pipelines, target profiles, and the vocabulary used for ordering and synchronization.

- [Ordering And Synchronization](ordering-and-synchronization.md) — synchronization primitives, event semantics, and dependency structure

2. Continue with [Ordering And Synchronization](ordering-and-synchronization.md) to understand synchronization primitives, event chains, and producer-consumer dependencies.
