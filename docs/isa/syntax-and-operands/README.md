# Syntax And Operands

This chapter describes PTO ISA textual spelling, operand shapes, attributes, and shared naming conventions. It is the prerequisite chapter for understanding instruction syntax.

## In This Chapter

- [Assembly Model](assembly-model.md) — PTO-AS syntax layers, operand modifiers, and immediate encoding rules
- [Operands And Attributes](operands-and-attributes.md) — operand categories, attribute families, and usage constraints

## Suggested Reading Order

Read this chapter before going deep into individual instructions so that the syntax forms and operand conventions used across the manual are familiar.

## Chapter Position

This chapter corresponds to Chapter 4 of the manual. Together with the chapters on state/types and memory model, it forms the knowledge base needed before instruction reference reading.
