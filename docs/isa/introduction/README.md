## Suggested Reading Order

1. Start with [What Is The PTO Virtual ISA](what-is-pto-visa.md) to understand PTO's positioning.
2. Continue with [Goals Of PTO](goals-of-pto.md) to understand the design intent.
3. Then read [Document Structure](document-structure.md) to understand how the manual is organized.
4. Finish with [Scope And Boundaries](design-goals-and-boundaries.md) and [PTO ISA Version 1.0](pto-isa-version-1-0.md) to understand the normative boundaries and baseline version decisions.
