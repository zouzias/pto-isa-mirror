# M2.3 RunGmm1 PTO int8 matmul

## 结论

M2.3 交付为 `review_ready`。`--backend int8` 在 M2 dispatch 后接入独立 `dav-c220-cube`
PTO-only GMM1 launcher，直接使用 `TMATMUL/TMATMUL_ACC` 执行 `int8 x int8 -> int32`，输出
`workspace.gmm1AccInt32`。

## 验收摘要

- clean build 通过，`moe_dispatch_combine_a8w8_gmm_kernel.cpp` 独立 cube target 可编译。
- single-rank small case：`m2.gmm1AccInt32` 与 host int32 reference 0 mismatch。
- two-rank balanced case：两个 rank 的 `m2.gmm1AccInt32` 均与 host int32 reference 0 mismatch。
- 当前 M2.3 smoke shape 固定 `hiddenSize=64`、`intermediateSize=32`；其他 shape 在后续 tiling 泛化前 fail-fast。

## 风险与下游提示

- M2.4 可直接消费 `gmm1AccInt32`；不得回退到 host numeric 或 mock accumulator。
- GMM2 仍需在 M2.6 复用同一 PTO-only cube launcher 体系或补同等 preflight。
