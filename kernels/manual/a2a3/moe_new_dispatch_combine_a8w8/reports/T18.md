# T18 Sync Optimization Report

## Scope

T18 只收敛 initquant 前重排内部 worker 协作同步；后置 count publish/wait、prefix/gather 和 stop17 final
visibility 仍保留 hard/mix 配对。

## Sync Pairing

stop17 当前 AIV 路径在 final sync 前原本有 11 个 mixed sync。审计后只把 3 个真正的 initquant 内部 phase
改成 AIV-only：

| Phase | AIV producer/consumer | Old scope | New scope |
| --- | --- | --- | --- |
| count done | worker count -> main AIV merge | hard/mix | AIV-only |
| prefix done | main AIV prefix -> worker scatter | hard/mix | AIV-only |
| scatter+quant done | worker scatter/quant -> count publish | hard/mix | AIV-only |

保留 mixed 配对的边界：

| Boundary | Reason |
| --- | --- |
| worker assignment/state clear/scratch clear | 仍用现有 AIC/AIV mixed 轮次配对，避免改变早期 stop 路径 |
| count publish/wait/prefix/gather | 属于 initquant 后置 dispatch/GMM 衔接 |
| stop17 final sync | host 验收前 GM 可见性和 AIC/AIV 同轮收口 |

AIC 侧 `M3NDispatchAicWaitForAivSubphases` 只在 production/stop17 路径扣减这 3 个 AIV-only phase；stop13、
stop18-stop21 等调试停止路径保持原 mixed 轮次。
