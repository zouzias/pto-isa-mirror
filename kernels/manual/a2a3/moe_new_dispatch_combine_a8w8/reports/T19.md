# T19 UB-Fits Full-Load Fast Path

## Scope

Implement the first PTO full-load initquant path for UB-fits shapes.

The path is selected by shape/capacity only:

- `R = M * topK <= 128`
- `K <= 1024`
- `globalExpertNum <= 16`
- `localRows >= R`

No device branch uses `caseName`, fixed `M`, or fixed `topK`.

## Implementation

- Added `M3NInitQuantFullLoadFits`.
- Added `M2RunInitQuantFullLoadPtoVec`.
- Main AIV full-load path keeps `count[expert]` and `cursor[expert]` in UB scalar scratch.
- Count/prefix/scatter metadata is generated directly without per-worker count/prefix scratch.
- Token payload uses existing token-centric PTO Vec quant through `M2QuantizeTokenToPackedRows`, so one source token quant can serve multiple valid topK routes.
- The three initquant internal phase syncs are skipped only for this single-AIV full-load path. Post-initquant count publish/wait, prefix/gather, ready, and stop17 final sync keep the existing synchronization contract.
- Host path summary reports `init_quant_dispatch_parallel_path=pto_full_load`.
