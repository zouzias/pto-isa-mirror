# T20 Large-Token Quant Pipeline

## Scope

- Target: initquant large-token path after full-load fallback is not selected.
- Keep PTO-only A8W8/int8 route quant path; no AscendC/Catlass fallback.
- Keep routine logs lean: only stop17 final acceptance summaries were used.

## Implementation

- `M2QuantizeTokenToPackedRows` now stays token-centric for every valid row count, including a single valid route.
- Valid packed rows for a token are cached in UB before scale/payload stores. The cache supports 256 routes per token and
  falls back to topK scanning only if that capacity is exceeded.
- Row quant uses ping/pong UB buffer groups for half/fp32/abs/int8 chunks. The int8 conversion helper now has independent
  s32/f16 scratch so it does not overwrite either ping/pong load buffer.
- Scale and payload store ordering added in this task uses PTO `PtoSetWaitFlag`; delayed load-ready record/wait uses PTO
  `Event<Op::TLOAD, Op::VECTOR>`.
