# T27 front-reorder fence/perf report

## Summary

T27 reduced the large anchor front-reorder window from about 540-580us to 27-28us on stop17.

Main changes:

- Removed route-quant hot-loop per-packed-row payload/scale `dcci+dsb`.
- Batched metadata publish by token range and expert/worker packed-row segment.
- Added stop17 stage timing fields: per-stage `prepare/count/prefix/route_pack_quant` and cumulative
  `e2e_after_*` boundary timings.
- Removed the front-reorder prepare path's full `gmm1InputInt8` clear; dispatch gather owns that buffer.
- Replaced debug lane-slot based dispatch worker assignment with dense local assignment for production/stop17.

## Verification

```bash
cmake --build kernels/manual/a2a3/moe_new_dispatch_combine_a8w8/build \
  --target moe_new_dispatch_combine_a8w8_mixed_spike --clean-first -j 16
```

Small stop17:

```bash
bash kernels/manual/a2a3/moe_new_dispatch_combine_a8w8/scripts/run_a3.sh \
  --backend int8 --m2-fused-full 1 --m2-fused-debug-stop-stage 17 \
  --dry-run 0 --skip-kernel-launch 0 --skip-build 1 --clean-build 0 \
  --case-name small-stop17 -pes 2 -M 16 -K 128 -N 128 -topK 2 \
  -expertPerPe 2 --max-output-size 32
```
