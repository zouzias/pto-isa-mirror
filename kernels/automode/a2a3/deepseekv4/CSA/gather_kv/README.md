# gather_kv — sparse_attn KV gather stage

Auto-mode A3 **vector** kernel scaffold. Stage 1 of the FlashAttention-style
sparse-attention pipeline (`sparse_attn_kernel` at
[deepseek/kernel.py:277-352](../../../../../../deepseek/kernel.py)).

## Pipeline position

The full sparse_attn body (kernel.py:321-343) is an inner loop over pipelined
blocks `t in [0, num_blocks)`, with `num_blocks = cdiv(topk, block)`. Each
iteration runs the five stages: **gather_kv → qk_matmul → online_softmax →
pv_matmul → (next iter)**, and the **output_rescale** tail runs once after
the loop. This leaf represents **gather_kv at one fixed `t`** (compile-time,
default `t = 0`). The driver that iterates `t` is not in this scaffold.

## Op (kernel.py:322-325)

```python
for i in T.Parallel(block):
    idxs[i] = T.if_then_else(t*block + i < topk,
                             topk_idxs[by, bx, t*block + i],
                             -1)
for i, j in T.Parallel(block, d):
    kv_shared[i, j] = T.if_then_else(idxs[i] != -1,
                                     kv[by, idxs[i], j],
                                     0)
```

## I/O

| Name | Shape | dtype | Source |
|------|-------|-------|--------|
| `kv` | `(kv_rows, D)` | BF16 | kernel.py:296 (`kv[by, ...]` row-slab of cache) |
| `topk_idxs` | `(TOPK,)` | INT32 | kernel.py:299 (`topk_idxs[by, bx, :]` row-slab) |
| `kv_gathered` | `(BLOCK, D)` | BF16 | kernel.py:303 (`kv_shared`) — single block |

`BLOCK ≤ 64` (default 32 in tiny case) and `D ≤ 128` keep one block tile
resident in UB.

## Memory-budget-first plan

Per [CLAUDE.md §Memory-budget-first kernel planning](../../../../../../CLAUDE.md):

```text
Memory budgets:
- L1 custom budget:    none (no L1 use in this leaf)
- L0A custom budget:   none (vector path, no cube)
- L0B custom budget:   none
- L0C custom budget:   none
- UB custom budget:    [kCsaBlock, kCsaD] BF16 out + [kCsaBlock] INT32 idx
                       ~= BLOCK*D*2 + BLOCK*4 bytes (well under 192 KB UB)

Live tiles by memory level:
- L1:  none
- L0A: none
- L0B: none
- L0C: none
- UB:  outTile (BF16, BLOCK x D), idxTile (INT32, BLOCK)

Smallest hardware operation:
- cube operation shape: N/A
- vector operation shape: scalar gather (row DMA) + vector fill (zero row)

Loop tiling plan:
- tile-and-loop dimensions: scalar loop over BLOCK rows
- inferred tile sizes: a single [BLOCK, D] UB tile (no inner tiling)
- compile-time unroll/peel strategy: none for prototype
- tail handling only where needed: global_i >= topk_len rows zeroed

Test-shape plan:
- tiny debug shape:        H=4,  D=32,  S=64,  BLOCK=32   (DEFAULT)
- medium tiling shape:     H=16, D=64,  S=128, BLOCK=64
- model-inspired realistic: H=16, D=128, S=512, BLOCK=64
- tail shape:              S not a multiple of BLOCK — Assumption: deferred,
                           tail-block driver will pad
```

## Auto-mode constraints

- A3 only; vector path: `--cce-aicore-arch=dav-c220-vec` (see
  [CMakeLists.txt](CMakeLists.txt)).
- Single AICORE. No `block_idx` work split.
- No `TASSIGN`, `TPipe`, `TPUSH`/`TPOP`, no raw `set_flag`/`wait_flag`,
  no `Tile::data()` pointer casts.
- A3 has **no MGATHER** (see `docs_for_ai/a3_a5_differences.md`); index-driven
  row copy is emulated with a scalar loop + per-row DMA. On A5 the body
  collapses to a single `MGATHER`.

## Comparison policy

- Exact: BF16 bit-pattern equality. Gather has no arithmetic.

## Known limitations

- Compile-time `t_block = 0` only; the outer pipelined loop is not in this
  scaffold.
- `kv_rows = S` for the prototype; real driver passes full cache length.
- A3 gather is scalar-loop-based; performance is not the focus of this leaf.
