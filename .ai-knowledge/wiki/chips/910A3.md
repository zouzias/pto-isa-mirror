# 910A3

## canonical scope

本页是 A3 / 910A3 硬件可见存储规格问题的轻量入口，当前只固定 PTO `TileType` 绑定时可见的片上空间容量，不扩写完整芯片 marketing 规格。

## canonical answer units
- `Vec / UB = 192 KB`
- `Mat / L1 = 512 KB`
- `Left / L0A = 64 KB`
- `Right / L0B = 64 KB`
- `Acc / L0C = 128 KB`
- `Bias = 1 KB`
- `Scaling / FBuffer = 2 KB`

## common confusion
- 不要把这页当完整 910A3 硬件规格表；它当前只覆盖 PTO 编程可见的 TileType 容量。
- 不要把 A2A3 的 `Acc / L0C = 128 KB` 套用到 A5。
