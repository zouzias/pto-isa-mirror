# 950A5

## canonical scope

本页是 A5 / 950 硬件可见存储规格问题的轻量入口，当前只固定 PTO `TileType` 绑定时可见的片上空间容量，不扩写完整芯片 marketing 规格。

## canonical answer units
- `Vec / UB = 256 KB`
- `Mat / L1 = 512 KB`
- `Left / L0A = 64 KB`
- `Right / L0B = 64 KB`
- `Acc / L0C = 256 KB`
- `Bias = 4 KB`
- `Scaling / FBuffer = 4 KB`
- `ScaleLeft / ScaleRight = 4 KB`

## common confusion
- 不要把这页当完整 950A5 硬件规格表；它当前只覆盖 PTO 编程可见的 TileType 容量。
- 不要把 A5 的 `ScaleLeft/ScaleRight` 默认套回 A2A3。
